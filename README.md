# Staunton Storm V2 preview

Dedicated preview of the supplied `staunton-storm-preview-v2.html`, served as `index.html`.

Preview address: https://otvagency.github.io/staunton-storm-site/

## Features
- Shop by Class for graduating classes 2027 through 2030.
- Mom, Dad, Student, and Family design previews.
- Alumni-year previews with validation for 1950 through 2026.
- Product filters, search panel, and mobile navigation.

Class-year merchandise is labeled as a design concept. Existing shopping links lead to the current store. This repository does not modify stauntonstorm.com, DNS, or other sites.

## Deployment
GitHub Pages: main branch, repository root. `.nojekyll` serves the supplied static HTML directly. The HTML includes its styling, scripts, and embedded images and requires no dependency installation or build.
